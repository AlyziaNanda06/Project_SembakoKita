# SembakoKita - E-Commerce

## Deskripsi Proyek
SembakoKita merupakan aplikasi e-commerce berbasis web yang menyediakan layanan penjualan kebutuhan sembako secara online. Aplikasi ini dibuat sebagai proyek mata kuliah E-Commerce kelas 2TI01.

## Teknologi yang Digunakan
- PHP Native
- HTML
- CSS
- JavaScript
- MySQL

## Fitur Aplikasi

### Halaman Pelanggan
- Login dan registrasi
- Beranda
- Melihat daftar produk
- Melihat detail produk
- Melihat daftar kategori produk
- Keranjang belanja
- Checkout
- Riwayat pesanan

### Halaman Admin
- Dashboard admin
- Kelola produk
- Kelola kategori
- Kelola pesanan
- Lihat website

## Cara Menjalankan Aplikasi
1. Clone atau download repository ini.
2. Simpan folder proyek ke direktori `htdocs`.
3. Import database `db_sembako_store.sql` melalui phpMyAdmin.
4. Sesuaikan konfigurasi database pada file `koneksi.php`.
5. Jalankan Apache dan MySQL melalui XAMPP.
6. Buka aplikasi melalui browser.
